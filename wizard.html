Freshdesk MCP Chat

Follow these steps to install and launch your AI support assistant.

1
Install Node.js
✓

Node.js 18 or newer is required to run the chat app and MCP server.

Download Node.js installer (nodejs.org)
Pick the LTS version and click through the installer defaults.

After installing, open Command Prompt and verify:

node --version

The easiest way is via Homebrew. If you don't have Homebrew, install it first:

/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"

Then install Node.js:

brew install node

Or download the macOS installer directly:

Download Node.js .pkg installer

Verify in Terminal:

node --version

Install via your package manager. Ubuntu / Debian:

curl -fsSL https://deb.nodesource.com/setup_lts.x | sudo -E bash - && sudo apt-get install -y nodejs

Fedora / RHEL:

sudo dnf install nodejs

Verify:

node --version
You should see v18.x or higher. If it shows an older version, upgrade before continuing.
2
Install Ollama Checking…
✓

Ollama runs the AI model locally — no cloud, no API key needed.

Download Ollama for Windows
Run the installer and wait for it to complete. Ollama will start automatically.
Download Ollama for macOS
Open the downloaded .dmg, drag Ollama to Applications, then launch it. It will appear in your menu bar.

Install with the official script:

curl -fsSL https://ollama.com/install.sh | sh
This installs Ollama as a systemd service that starts automatically.
RAM required: ~2 GB free. The model loads into memory on first chat. Fine on 16 GB machines.
3
Download the AI model (~2 GB) Checking…
✓

Open a terminal and run the command below. This downloads the model once — no repeats needed.

ollama pull qwen2.5:3b
A progress bar will appear. Wait for "success" before continuing.
Ollama is running — but the model isn't pulled yet. Run the command above in a terminal.
4
Add your Freshdesk credentials
✓

Enter your Freshdesk subdomain and API key. The wizard will save them as a .env file in your app folder.

Keep .env private. It contains your API key — don't share it.
5
Run setup (one time only)
✓

Double-click setup.bat in the folder. A terminal will open, install dependencies, and show "Setup complete!"

If Windows SmartScreen warns you, click "More info" → "Run anyway".

Open Terminal, navigate to the app folder, and run:

bash setup.sh
If you get a permission error, run chmod +x setup.sh first, then try again.

Open a terminal in the app folder and run:

bash setup.sh
One time only. You won't need to do this again on future launches.
6
Launch the chat app Checking…
✓

Double-click start.bat. Keep the terminal window open while using the app.

In Terminal, run:

bash start.sh

In a terminal, run:

bash start.sh
http://localhost:3000
Open Freshdesk Chat →
Daily use: just run the start script and open http://localhost:3000. No other steps needed.
7
Connect Claude Desktop (optional)
✓

Use the MCP server with Claude Desktop or any other MCP-compatible LLM client — alongside or instead of the built-in chat app.

Option A — Stdio (recommended, works everywhere)
Claude Desktop spawns the MCP server directly as a child process. No HTTP server needed.

Config file: %APPDATA%\Claude\claude_desktop_config.json

{ "mcpServers": { "freshdesk": { "command": "node", "args": ["C:\\Users\\YourName\\freshdesk-mcp\\mcp-server\\index.js"] } } }

Replace C:\Users\YourName\freshdesk-mcp with your actual install path. Set FRESHDESK_DOMAIN and FRESHDESK_API_KEY in your .env file — the server reads it on startup.

Config file: ~/Library/Application Support/Claude/claude_desktop_config.json

{ "mcpServers": { "freshdesk": { "command": "node", "args": ["/Users/yourname/freshdesk-mcp/mcp-server/index.js"] } } }

Replace /Users/yourname/freshdesk-mcp with your actual install path.

Config file: ~/.config/Claude/claude_desktop_config.json

{ "mcpServers": { "freshdesk": { "command": "node", "args": ["/home/yourname/freshdesk-mcp/mcp-server/index.js"] } } }

Replace /home/yourname/freshdesk-mcp with your actual install path.

Option B — HTTP endpoint
The HTTP MCP server runs on port 3001 and accepts POST /mcp. Start it alongside the chat app:

node mcp-server\http-server.js
node mcp-server/http-server.js
node mcp-server/http-server.js

Endpoint: http://localhost:3001/mcp. Use with any client that supports the MCP Streamable HTTP transport. For Claude Desktop, use Option A (stdio) — it's simpler and has no extra process to manage.
