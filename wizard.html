Freshdesk MCP Chat

Follow these steps to install and launch your AI support assistant.

1
Install Node.js
✓

Node.js is the runtime that powers the chat app and MCP server. Download and run the Windows installer — click "Next" through the defaults.

Download Node.js (nodejs.org)
Version required: 18 or newer. On the download page, pick the LTS version — it's the default.

After installation, open Command Prompt (press Windows key, type cmd, press Enter) and run:

node --version
You should see something like v22.0.0. Any v18+ is fine.
2
Install Ollama
✓

Ollama is the local AI runtime. It runs the language model on your machine — no cloud, no API key. Download and run the Windows installer.

Download Ollama for Windows
RAM required: ~2 GB free. The model itself is about 2 GB and loads into memory when you first chat. On a 16 GB machine this works fine.
3
Download the AI model (~2 GB)
✓

Open Command Prompt and run the command below. It downloads the model — this only needs to happen once.

ollama pull qwen2.5:3b
This will show a progress bar and take a few minutes depending on your internet speed. Wait until you see "success" before continuing.
4
Add your Freshdesk credentials
✓

Open the file named .env in the same folder as this page. It should already exist — if not, copy .env.example and rename it to .env. Fill in two values:

FRESHDESK_DOMAIN
Your Freshdesk subdomain. If your helpdesk URL is acme.freshdesk.com, enter acme.
FRESHDESK_API_KEY
Your personal API key. In Freshdesk: click your avatar (top right) → Profile Settings → scroll to Your API Key.
Keep .env private. It contains your API key. Don't share it or commit it to git.
5
Run setup (one time only)
✓

Double-click setup.bat in the folder. It installs the app's dependencies. A terminal window will open, show progress, and close with a "Setup complete!" message.

If you see a Windows SmartScreen warning, click "More info" then "Run anyway". This is normal for scripts that aren't signed.
You only need to do this once. Skip this step on future launches — go straight to Step 6.
6
Launch the chat app
✓

Double-click start.bat. It starts Ollama (if not already running) and launches the chat app. A terminal window will stay open — keep it open while you use the app.

After a few seconds, open your browser and go to:
http://localhost:3000
Open Freshdesk Chat →
Daily use: from now on, just double-click start.bat and open http://localhost:3000. No other steps needed.

You're all set!

The Freshdesk Chat app is installed and running. Bookmark http://localhost:3000 for daily use.
